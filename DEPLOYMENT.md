# Deployment checklist

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Keep the framework preset as Next.js.
4. No environment variables are required for the current demo.
5. Deploy and open the generated URL.
6. Verify dashboard, task execution, approval/rejection, and report workflow.

**Do not describe this version as production-ready.** It uses in-memory client state and fictional data. Add a persistent database, server-side task engine, authentication, and automated tests before using it for real business workflows.
